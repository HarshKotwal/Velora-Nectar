# 🍷 Velora Nectar – GSAP Luxury Cocktail Experience

Velora Nectar is a premium, scroll-driven cocktail website built using React, GSAP, and Tailwind CSS.

It delivers a cinematic storytelling experience through advanced animations, scroll-triggered timelines, video synchronization, parallax depth effects, and immersive section transitions.

This project demonstrates modern front-end animation architecture using GSAP in a real-world luxury product concept.

---

## ✨ Features

- Scroll-driven cinematic storytelling
- GSAP SplitText animated typography reveals
- ScrollTrigger-powered timeline control
- Pinned sections for immersive transitions
- Scroll-synced background video playback
- Image masking and parallax effects
- Custom animated carousel
- Multi-section timeline choreography
- Fully responsive animation logic
- Optimized video performance for web delivery

---

## 🛠️ Tech Stack

### Frontend

- React (Vite)
- GSAP (ScrollTrigger, SplitText)
- Tailwind CSS
- React Responsive
- Custom reusable animation hooks

## ⚙️ How It Works

1. Hero Section Animation

- Cinematic intro with animated typography
- Smooth entrance transitions using GSAP timelines

2. Scroll-Based Storytelling

- ScrollTrigger controls animation timing
- Sections pin and animate as user scrolls

3. Video Sync

- Background video playback synced to scroll position
- Optimized compression for fast loading

4. Interactive Components

- Custom animated carousel
- Masking and reveal effects
- Parallax depth motion

5. Responsive Experience

- Animations adapt to screen size
- Layout optimized for desktop and mobile
